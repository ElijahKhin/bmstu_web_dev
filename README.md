## Лабораторная работа №1

## Разработка интернет-приложений

### Тема проекта

Расчет индекса потребительских цен (ИПЦ) для персональной потребительской корзины.

### Описание

Веб-приложение позволяет пользователю рассчитать персональный индекс инфляции на основе выбранных категорий товаров и услуг (например: продукты, ЖКУ, транспорт, одежда).

Каждая категория имеет вес в потребительской корзине и данные об изменении цен за выбранный период. Пользователь может выбрать несколько категорий и получить расчет персонального индекса инфляции.

### Функциональность

Приложение содержит три страницы:

1. **Services** — список категорий товаров и услуг с поиском.
2. **Service details** — страница конкретной категории с подробным описанием.
3. **Order** — персональная корзина пользователя и расчет индекса инфляции.

### Технологии

* **Backend:** Python + FastAPI
* **Шаблоны:** Jinja2
* **Дизайн:** Figma
* **Хранение медиа:** MinIO

### Особенности реализации

* Используются **3 GET маршрута** для отображения страниц приложения.
* Данные хранятся в памяти приложения (коллекция категорий и словарь заявки).
* Изображения и видео загружаются из **MinIO**.
